# Удаление пользователя

## Подготовка

- Авторизуйся демо-администратором.
- Возьми демо-пользователя Илью Орлова из стартового списка.

## Шаги

1. Открой страницу «Пользователи».
2. В строке Ильи Орлова нажми «Удалить».
3. В модалке подтверждения нажми «Удалить».

## Проверка

- В модалке был текст с именем Ильи Орлова.
- Строка с email `ilya@example.com` исчезла из таблицы.
- Показан тост «Пользователь удалён».
