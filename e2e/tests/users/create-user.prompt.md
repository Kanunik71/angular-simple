# Создание пользователя

## Подготовка

- Авторизуйся демо-администратором.
- Используй стартовый список пользователей.

## Шаги

1. Открой страницу «Пользователи».
2. Нажми «Добавить».
3. Заполни форму: имя `Иван Тестов`, email `ivan@example.com`, роль «Пользователь».
4. Нажми «Сохранить».

## Проверка

- Приложение вернулось на страницу «Пользователи».
- В таблице есть строка с email `ivan@example.com` и именем `Иван Тестов`.
- В строке отображается роль «Пользователь».
- Показан тост «Пользователь создан».
