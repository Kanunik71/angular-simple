# Редактирование пользователя

## Подготовка

- Авторизуйся демо-администратором.
- Создай пользователя: имя `Иван Тестов`, email `ivan@example.com`, роль «Пользователь».

## Шаги

1. Открой страницу «Пользователи».
2. В строке с email `ivan@example.com` нажми «Изменить».
3. Замени имя на `Иван Изменённый`, email на `ivan.changed@example.com`, роль на «Администратор».
4. Нажми «Сохранить».

## Проверка

- Приложение вернулось на страницу «Пользователи».
- В таблице есть строка с email `ivan.changed@example.com` и именем `Иван Изменённый`.
- В строке отображается роль «Администратор».
- Показан тост «Пользователь сохранён».
